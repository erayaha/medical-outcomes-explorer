# Data snapshots

Versioned JSON snapshots live under `/data/YYYY-MM` so the frontend can remain fully static and GitHub Pages compatible.

Included starter files:

- `hospitals.json` – hospital metadata and longitudinal outcome samples
- `measures.json` – plain-language measure and program definitions
- `devices.json` – device class summaries, recalls, and adverse-event counts
- `device_to_measure_map.json` – heuristic mappings between device classes and hospital measures
